# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Star ratings: 3 stars at par, 2 within two moves of par, 1 for any solve, shown on the solved screen and next to your best score.

## [0.1.0] - 2026-11-03

### Added

- Beam tracing with emitters, crystals, walls, turnable mirrors and fixed mirrors.
- 10 levels, all verified by the bundled solver.
- pygame window with click-to-turn mirrors, undo, restart, hints and next/previous level.
- Saved progress and best move counts in the user data folder.
- Plain-text level format, `--levels` for custom level folders, `--level` and `--reset-progress`.
